Engineering Guidance

How to Choose the Right Calculator for Your Project

Select your starting parameter below to immediately launch the optimal civil engineering calculation workflow.

📐

By Known Project Dimensions

When you have site length, width, and specified compacted thickness:

  • Use Asphalt Tonnage Calculator for single-lift paving and driveways.
  • Use Road Asphalt Calculator for multi-course roadways with shoulders.
  • Use Circular Calculator for roundabouts and turning circles.
⚖️

By Delivered Plant Dockets

When verifying delivered weight tickets against actual paved coverage on site:

  • Use Asphalt Thickness QC to reverse weight + area into compacted depth.
  • Use Square Metres Tool to check tonnes vs. coverage.
  • Use Application Rate Tool for kg/m² rate compliance.
🌍

By Local Authority Standards

When bidding public highway contracts or conforming to state DOT standards:

  • Use Regional Calculators for State DOT & provincial mix defaults.
  • Use Tack Coat Calculator for emulsion spray specs.
  • Use Project Cost Estimator for local currency budgets.
